## A　插座、盤體與電氣接點 {#recording-a}

回看：00:01:15–00:07:14。目標：放入裝置，分清楚名稱與實際電氣資料。

1. 在練習專案中載入所需的插座與配電盤族群（Load Family），或把 .rfa 拖入專案。這次附件沒有提供族群檔，請使用公司核可或自己已有的教材。
2. 在平面圖按配置位置放置插座及配電盤，檢查安裝高程與宿主（Host）。牆式插座需要適合的牆宿主；連結模型上的放置方式需另確認族群支援。
3. 選取插座與盤體，檢查其電壓、極數等電氣資料。錄音示範插座為 220 V，盤體原始類型出現 208 V；這是課堂例子，不是專案設計值。
4. 若盤體資料無法在專案中修改，選取盤體 → 編輯族群（Edit Family），在族群編輯器選取**電氣接點（Electrical Connector）**，於性質檢查電壓、極數及系統類型。若接點已關聯參數，須檢查該參數的控制方式。
5. 以新的練習名稱另存族群，再載入練習專案。遇到同名族群時，先確認覆寫選項；「覆寫既有版本及其參數值」可能改變已放置實例使用的類型資料。
6. 要讓類型名稱反映資料，可在專案瀏覽器 → 族群 → 電氣設備中找到對應類型並更名。**更名只改名稱，不會替你修改接點或建立配電系統。**

完成檢查：能指出裝置及盤體的實際電氣接點資料；名稱與電壓相符；重載後既有實例的尺寸及資料沒有意外變動。

## B　電壓定義、配電系統與迴路 {#recording-b}

回看：00:10:41–00:16:14。目標：能把一組相容裝置指定到配電盤。

### B1　先補齊配電設定

1. 開啟電氣設定（Electrical Settings）；通常可由管理 → MEP 設定進入，錄音也從系統頁籤開啟。
2. 在電壓定義（Voltage Definitions）新增專案需要的標稱電壓及上下限。上下限依設計要求填寫，逐字稿未提供可採用的確定數值。
3. 在配電系統（Distribution Systems）新增或檢查系統，確認相位、組態、導線數、線對線（L-L）與線對地（L-G）電壓。
4. 選取盤體，指定相容的配電系統；再檢查裝置接點的電壓及極數是否能與該盤體配對。

> 課堂曾暫把三相 Y 型、四線的 L-L 與 L-G 都設為 220 V，講師也明說不知道實際專案的 L-G。此設定不可照抄成設計值。一般平衡三相 Y 接有 L-L ≈ √3 × L-G 的關係，實際數值、接地方式及供電系統應依專案電力系統圖確認；「軟體能連上」不等於電氣設計正確。

### B2　建立並指定迴路

1. 選取要加入同一迴路的插座。右鍵「選取所有實例」（Select All Instances）可加快選取，但務必確認是目前視圖還是整個專案，並移除不屬於本迴路的裝置。
2. 使用動力／電力（Power，名稱依版本）建立電氣迴路。
3. 在迴路工具使用選取配電盤（Select Panel），指定適合的盤體。
4. 若回到一般選取狀態，可將游標停在裝置上按 Tab，確認預選提示為迴路後再點選，避免把裝置或其他連接物誤當迴路。
5. 確認迴路已有盤體名稱及迴路資料；若無法指定，回查接點、極數、電壓定義與盤體配電系統，不能只改盤體名稱。

完成檢查：每個預定裝置都在正確迴路內，盤體欄位有值；變更設定後再確認相容性。完整電氣流程與負載表見既有[電氣迴路與配電教材](../給排水與視圖教材/07_電氣迴路與配電教材.md)。

## C　2D 電線、線數與符號 {#recording-c}

回看：00:15:29–00:16:14、00:19:51–00:23:32。目標：產生清楚的平面配線圖。

1. 選取已建立的迴路，使用弧形電線（Arc Wire）產生圖示。
2. 選取電線，拖曳控制點，調整弧線以避開文字、符號與相鄰圖示。
3. 在電線性質檢查火線、中性線與地線數量，依迴路及公司圖例要求調整；線數不是任意的視覺裝飾。
4. 到電氣設定的佈線相關項目檢查線數刻痕／符號樣式（Tick Marks）。錄音舉例切換圓形與鉤形，但沒有確定公司採用的圖例，請依圖例表設定。
5. 用出圖比例檢查弧線與刻痕是否可讀，再確認盤體及迴路資料仍正確。

**2D 電線圖示、電氣迴路與實際電管／電纜路徑是不同層次。** 不能把平面弧線長度當成現場拉線長度；也不能把錄音的「沒有辦法運算」延伸成 Revit 完全不能計算電氣資料。迴路路徑與計算相關設定另見既有教材 E07。

錄音 00:22:17–00:23:32 轉談「建立類似」與電纜架的弱電設定，語句辨識不清。可採用的檢查原則是：開始新一段前確認類型、尺寸、高程及服務類型，不假設前一段設定一定沿用。

## D　樓層視圖與跨樓層複製 {#recording-d}

回看：00:27:47–00:34:53。目標：把標準層模型複製到指定樓層，逐層驗收。

1. 先確認目標標高（Level）已存在，再於視圖 → 平面視圖建立所需樓層平面。**新增平面視圖不會自動新增標高，也不會複製模型。**
2. 若領域、次領域或可見性欄位呈灰色，檢查指定的視圖樣板。可在練習視圖先設為「無」，或依下一單元調整樣板的「包括」，正式專案則應遵守樣板管理流程。
3. 回到標準層，只選取需要複製的模型元件。利用篩選器移除標註、基準點、連結等無關物件；2D 電線與註解另行處理。
4. 複製到剪貼簿（Copy to Clipboard）→ 貼上 → 與選取的樓層對齊（Aligned to Selected Levels），先選一個目標樓層測試。
5. 檢查宿主、相關樓層、偏移、高程、重複元件與警告。牆式元件可能因缺少合適宿主而失敗；出現警告時應先處理，再擴大複製。
6. 確認測試層正確後，再複製其餘樓層；逐層檢查迴路、盤體與 2D 圖示，不能假設它們已隨模型自動完成。
7. 在 3D 檢查整體位置。剖面框（Section Box）未顯示時，先分清楚「裁切是否啟用」和「框線品類是否可見」，再看視圖性質、VG 的註解品類、隱藏狀態與樣板控制。

完成檢查：每層只有預期數量的模型；高程及宿主正確；沒有未處理的複製警告；2D 與迴路已另外驗收。

## E　視圖樣板的兩種套用方式 {#recording-e}

回看：00:36:30–00:43:45。目標：知道何時要持續受控，何時只帶入設定。

| 做法 | 操作 | 後續行為 |
| --- | --- | --- |
| 指定視圖樣板（Assign View Template） | 在目標視圖性質指定樣板 | 樣板勾選「包括」的項目持續受控，在視圖中通常無法直接修改 |
| 將樣板性質套用到目前視圖（Apply Template Properties to Current View） | 使用一次性套用功能 | 帶入樣板包括的設定，不因此建立持續控制關聯；原有樣板若仍受指定，仍要檢查其控制 |

### E1　建立可重用的樣板

1. 選一張已調好的工作視圖，確認比例、詳細等級、領域、VG、篩選器及連結顯示。
2. 使用從目前視圖建立樣板（Create Template from Current View），命名例如 `SCADA_電氣_工作`。
3. 開啟管理視圖樣板（Manage View Templates），逐項決定「包括（Include）」。例如工作圖可不包括比例與詳細等級，讓各張視圖自行調整；正式出圖樣板可另建並保持必要控制。
4. 先指定給一張測試視圖；確認應鎖定的項目受控、應開放的項目可改，再套用其他視圖。

### E2　只取用一次設定

1. 若只需要帶入設定，使用「將樣板性質套用到目前視圖」。
2. 選定樣板後套用，檢查目標視圖的設定與「視圖樣板」欄位。
3. 修改樣板中的一個測試項目，觀察一次性套用視圖與指定樣板視圖的差異；完成後復原測試變更。

「包括」未勾選，代表該項不由此樣板控制／帶入，不是關閉該項功能。解除一張視圖的樣板，也不代表把既有外觀還原為預設。延伸可讀本站「把上色設定存成視圖樣板並套用」。

## F　座標、匯出顏色與碰撞檢查 {#recording-f}

回看：00:25:25–00:27:35、00:51:25–00:57:09、01:12:37–01:15:28。

### F1　先對齊，再談碰撞

錄音提到整合後模型跑到遠處。請先與協調方確認共同座標、基準點、單位及匯出設定，用已知軸線交點與標高核對位置。不要單憑畫面看似重合就任意平移正式模型；若上游模型有錯，記錄錯誤並協調修正基準。

### F2　電纜架與電管的顏色

1. 檢查電纜架、電纜架配件、電管及電管配件的服務類型等分類欄位。
2. Revit 工作視圖可用篩選器上色；錄音「沒有辦法設定顏色」不宜當成通則。
3. 錄音示範從物件型式（Object Styles）調整品類材料，作為匯出顏色的處理方向。物件型式是全專案品類層級設定，不能直接區分同品類內的兩個系統；元件或族群材料也可能另有控制。
4. 匯出前先用小範圍測試檔驗證顏色、配件及連結內容，不能假設視圖篩選的顏色必然完整帶入 Navisworks。依 BEP 確認交付顏色與模型分檔方式。

錄音當時提到 NWC 匯出器尚未裝好，因此不把此段寫成「已驗證匯出成功」。安裝與版本相容性應由公司流程處理；完整匯出步驟可讀本站「匯出 NWC 並整合到對方的 NWD」與「只匯出自己的系統」。

### F3　Navisworks 碰撞測試

**選修與軟體前提**：Clash Detective 是 Navisworks Manage 的功能；Freedom／Simulate 不能取代它執行同樣的碰撞測試。沒有 Manage 時，可閱讀既有碰撞報告或由協調方執行，不影響本站 Revit 必要流程。

1. 在 Manage 載入位置、單位已核對的協調模型，開啟 Clash Detective，新增測試。
2. 依系統或選集設定 Selection A 與 Selection B，例如弱電電纜架對消防管線，避免重複模型對撞造成假結果。
3. 依 BEP 決定測試類型與公差；實體相交（Hard）與淨空要求（Clearance）應分開判讀。錄音沒有提供可直接使用的公差值。
4. 檢查納入的幾何類型與測試範圍後執行，逐筆定位結果，記錄樓層、系統、元件識別與問題截圖。
5. 回 Revit 修改，再重新匯出及測試，確認原問題解除。不要只看總碰撞數量降低。

錄音提及可以返回 Revit 定位，但講師未確認按鈕位置。SwitchBack 是否可用需核對軟體版本、連結與設定；本章不提供猜測的按鈕路徑。無此功能時，以元件 ID、軸線及標高定位。

## G　族群樣板、工作平面與五種造型 {#recording-g}

回看：01:17:24–01:43:18。目標：選對造型工具，辨認工作平面與模型方向。

### G1　建立族群前先決定用途

1. 檔案 → 新建 → 族群（Family），選擇適合的 .rft。確認是牆式、面式、工作平面式或非宿主，以及最後應歸的品類。
2. 錄音疑似提到「公制通用模型」，但現場找不到樣板；請依安裝內容核對名稱，不把其他樣板當成完全等效。
3. 以參考平面建立定位基準，對照參考樓層、前／後／左／右及 3D 視圖，確認工作平面（Work Plane）。
4. 用簡單形狀練習造型，完成後另存 .rfa，再載入練習專案檢查方向與尺寸。

**方向取決於工作平面與工具設定，不只取決於目前看的視圖。** 錄音以上視圖／前視圖解釋垂直或水平造型，是示範當時的設定，不是所有族群的固定規則。箱體外形也不會自動具有盤體的電氣功能；需要迴路時，仍須設定適當品類及電氣接點。

### G2　五種工具怎麼選

| 工具 | 幾何條件 | 練習與回看 |
| --- | --- | --- |
| 擠出（Extrusion） | 封閉截面沿工作平面法向伸長 | 箱體或圓柱；01:22:02–01:24:43 |
| 混成（Blend） | 底部與頂部兩個輪廓之間漸變 | 方轉圓或大小漸變；01:24:48–01:26:18 |
| 迴轉（Revolve） | 封閉剖面繞軸旋轉 | 對稱套筒或杯形；01:26:32–01:29:20 |
| 掃掠（Sweep） | 一個截面沿路徑延伸 | 軌道或邊緣造型；01:30:30–01:37:44 |
| 掃掠混成（Swept Blend） | 沿單一路徑段在兩端截面之間漸變 | 轉彎且變徑的配件；01:40:18–01:43:18 |

### G3　跟做步驟

1. **擠出**：設定工作平面 → 畫無自交的封閉輪廓 → 確認起點與終點／深度 → 完成 → 3D 檢查。要空心時可用外內封閉輪廓，或另建空心形式並確認切割結果；不要為不可見細節增加不必要幾何。
2. **混成**：建立底部封閉輪廓 → 編輯頂部 → 畫另一截面 → 確認高度與頂點對應 → 完成。若扭轉或失敗，檢查輪廓、頂點連接及高度。
3. **迴轉**：在合適工作平面繪製封閉剖面 → 設定旋轉軸 → 確認旋轉角度 → 完成。檢查剖面是否跨軸或造成自交。
4. **掃掠**：先畫／選取連續路徑 → 選取或編輯輪廓 → 切到適合輪廓平面的視圖 → 將封閉截面放在路徑的輪廓位置 → 完成輪廓及掃掠 → 3D 檢查轉角。輪廓不是直接畫在任意平面上。
5. **掃掠混成**：建立工具允許的單一路徑段 → 編輯兩端截面 → 確認尺寸、方向及對應 → 完成。複雜多段造型先分段測試，再檢查接縫；完整路徑限制與特定曲線是否支援，需對照實際版本驗證。

完成檢查：各造型在 3D 中方向與尺寸正確；截面封閉且無自交；修改尺寸後仍能重建。若要做成可用設備，另測品類、參數、宿主、接點與專案載入行為。相關參數設計見本站「在族群新增自訂參數到『識別資料』」。

## H　綜合練習與排查 {#recording-h}

先另存練習專案。以下為本章新增練習，不是錄音中的既定作業或決議。

| 練習 | 操作 | 驗收證據 |
| --- | --- | --- |
| 一組插座迴路 | 放置數個插座與一台盤體，建立電壓定義／配電系統並指定迴路 | 裝置清單、盤體名稱、相容的電壓與極數；弧線及符號可讀 |
| 一層模型複製 | 只複製需要的模型到另一樓層 | 兩層數量、高程及宿主正確；警告已處理；2D 與迴路另查 |
| 比較樣板套用 | 各用一張視圖測試指定樣板與一次性套用 | 能說明「包括」與持續控制的差異 |
| 五種造型 | 在練習族群各做一個簡單造型 | 3D 方向正確，可調整尺寸並載入專案 |
| 選修：碰撞複測 | Manage 中測試兩組系統，修正一筆再重測 | 前後結果、模型版本與定位證據能對應 |

| 症狀 | 優先檢查 |
| --- | --- |
| 無法指定配電盤 | 迴路是否建立、裝置接點電壓／極數、盤體配電系統 |
| 改名後仍無法連接 | 名稱不會改電氣接點或配電系統 |
| 欄位灰色不能改 | 視圖樣板及該欄位是否勾選「包括」 |

| NWC 顏色與 Revit 不同 | 視圖覆寫與材料的差別、匯出設定、元件／族群材料 |
| 掃掠輪廓畫不出來 | 路徑、輪廓位置、工作平面與適合的視圖 |
| 模型遠離整合模型 | 座標、單位、基準與匯出範圍 |
