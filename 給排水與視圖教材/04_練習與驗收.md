# 練習與驗收

本文件的作業、測試數值與評分方式為教材新增。操作依 Revit 繁體中文介面的功能與課程案例編排，不是原講師的指定作業。每題在專案／族群副本進行，保留成果與問題紀錄。

## 作業一　建立可以核對的機電工作環境

對應 M01–M12、R09。

1. 從適當樣板建立一個機電練習專案，連結建築 RVT。
2. 複製／監視需要的樓層及網格，為目標樓層建立樓板與天花板反射平面。
3. 連結建築及排水 DWG，逐一記錄原繪圖單位、放置方式與已知控制點。
4. 放置一組馬桶、臉盆、蓮蓬頭與落水頭，核對主體、中心及接點。

交付：RVT 副本、平面與立面截圖、連結與單位紀錄表。

| 驗收項目 | 通過條件 | 結果／證據 |
| --- | --- | --- |
| 樓層與網格 | 能與連結來源核對，無非預期重複基準 | 待填 |
| 平面圖 | 各視圖關聯樓層正確 | 待填 |
| CAD 比例 | 一個已知尺寸及兩方向對位均正確 | 待填 |
| 器具主體 | 壁掛與落地元件放置方式正確 | 待填 |
| 可見性 | 可解釋器具在不同視圖中看見／看不見的原因 | 待填 |

## 作業二　排水系統與高程

對應 M13–M24。案例縮寫與管徑依自己的練習模型設定。

1. 建立 SP、WP、VP 三組可辨認的立管，記錄管類型與系統類型。
2. 為馬桶及臉盆路徑各建一張沿管心方向的剖面。
3. 將器具接至對應管線，使用合適的分支、存水彎與檢修末端。
4. 以課堂示範的 1% 做一段教學管路，標出繪製方向及實際高低端；其他實際設計值不由本題決定。
5. 在 3D 逐一追查器具至幹管，不以肉眼碰到就認定接點連通。

交付：RVT 副本、兩張局部剖面、開口與配件問題清單。

檢核問答：一段水平投影長 5000 mm 的教學管路，坡度為 1%，兩端高差多少？參考答案為 50 mm；這是坡度幾何練習，仍需以模型實際量測核對兩端位置。

## 作業三　標註、管長與耗損

對應 M25–M35、R11 標籤部分。

1. 為器具建立 X、Y 定位尺寸，基準採已確認的牆面或網格。
2. 製作包含系統與大小的管標籤，為局部管段建立 TOP、BOP 與 COP 標示。
3. 建立管配件數量表及管長表，保留用於分組的系統與規格欄。
4. 新增教材教學用耗損欄，假設比例為 20%，模型量與估算量分欄。

### 已知量測試

在專用測試區建立兩段同系統、同規格、不帶斜度的直管，長度分別為 4000 mm 與 6000 mm。用測試識別欄或其他明確篩選條件讓明細表只計這兩段。

| 欄位 | 預期值 | 實測值 |
| --- | --- | --- |
| 模型長度 | 10000 mm／10 m | 待填 |
| 20% 耗損長度 | 2 m | 待填 |
| 含耗損長度 | 12 m | 待填 |

若結果不符，依序查：統計範圍、分組條件、格式是否計算總數、公式比例及單位格式。TOP／BOP／COP 需在剖面核對取樣位置，不能只看文字前綴。

## 作業四　給水配管與干涉閉環

對應 M36–M46。

1. 建立可辨認的冷水、熱水管類型及系統，配置適用管段、尺寸與配件。
2. 先在測試區檢查轉彎、三通與變徑，再完成器具配管。
3. 在測試副本故意安排一個可檢出的實體相交。
4. 執行干涉檢查，記錄品類、模型範圍及衝突元素。
5. 改線排除衝突，重新整理既有報告後，再完整執行相同範圍檢查。

交付：兩次完整檢查的結果、改線前後截圖、檢查範圍說明。驗收要求能解釋 Refresh 與重新執行的差異。必要的檢修或操作空間另行檢查，不以實體碰撞結果取代。

## 作業五　參數化閥件與巢狀控制

對應 R01–R04。

1. 製作一個帶寬、長、高控制的本體，先設參考平面再約束幾何。
2. 加入一個獨立六角零件，關聯至主體的大小與長度參數。
3. 建立兩端管接點，將尺寸關聯至用途明確的管徑參數。
4. 製作三組不會形成負尺寸或幾何自交的測試尺寸，依序改值再回復。
5. 將 RFA 載入測試專案，檢查主體控制、尺寸變化及兩端接管。

| 測試 | 通過條件 | 結果／證據 |
| --- | --- | --- |
| 增減總尺寸 | 中心與約束維持正確 | 待填 |
| 改子零件大小 | 能由主體參數控制 | 待填 |
| 改分段高度 | 只有預定的段落及從屬位置改變 | 待填 |
| 兩端連管 | 接點方向、尺寸及系統用途相容 | 待填 |
| 專案端測試 | 類型／實體參數影響範圍符合設計 | 待填 |

參考問答：兩個同類型元件，只想改其中一個高度，應先評估什麼？答案：高度是否應設為實體參數，或是否需要複製成另一類型。不要直接修改共用的類型高度後期待另一個不變。

## 作業六　盤體與電氣迴路

對應 R05、R11。

1. 建立或使用有合適品類與電氣接點的盤體，設定寬、高、深及可切換的開門範圍。
2. 為盤體及裝置核對電壓、極數、系統類型和適用配電系統。
3. 建立一組包含兩個相容裝置的測試迴路，指定配電盤。
4. 建立負載表，核對兩個裝置均屬於預定迴路及盤體。
5. 另建一段電管或電纜架實體路徑，說明它與電氣迴路的差異。

交付：RFA／RVT、接點屬性截圖、迴路與負載表。這是軟體功能練習，電壓與負載使用明確的測試資料；不推定原課程示例可作為本專案的電氣設計值。

## 作業七　視圖篩選、樣板與材料

對應 R06–R08、M46。

1. 建立兩個可辨認的系統，測試品類開關與依規則篩選的差異。
2. 準備三個元件，讓它們分別符合單一條件及雙條件，驗證 AND／OR。
3. 對兩張同用途視圖指定同一樣板，修改已包括的設定，確認兩張圖同時改變。
4. 再用另一張獨立視圖只套用一次樣板性質，修改樣板後比較結果。
5. 為兩類測試路徑規劃分類與材料，完成小範圍匯出並記錄外觀結果。

交付：規則表、樣板包括欄截圖、兩種樣板使用方式的比較、材料／匯出紀錄。

## 自我測驗與參考答案

| 題目 | 參考答案 |
| --- | --- |
| 關掉「管」品類後，只想顯示冷水，光打開冷水篩選可以嗎？ | 先恢復品類可見，再依規則篩選不同系統，並查其他取代與樣板。 |
| 複製／監視樓層後一定自動有平面圖嗎？ | 不一定；核對平面視圖是否已建立。 |
| 共用參數 TXT 會自動保存各專案所有元件的數值嗎？ | 它主要保存參數定義；實際值另存在對應模型或族群。 |
| 族群用一般模型畫成箱子就一定能當配電盤嗎？ | 不能僅靠外形判斷，要檢查品類、接點、零件類型與配電設定。 |
| 只畫了電管就代表裝置已加入電氣迴路嗎？ | 否；需要相容電氣接點、迴路與盤體設定。 |
| 管標籤讀到的某端高程等於標籤落點的高程嗎？ | 有坡度時未必；檢查參數含義並用剖面或定點標註驗證。 |
| 另存所有族群就包含管類型的全部設定嗎？ | 可載入族群與系統族群不同，需另核對管類型及搬移內容。 |
| 原干涉報告清空是否代表整案無碰撞？ | 不能；需重新執行明確範圍檢查，並記錄未納入部分。 |
