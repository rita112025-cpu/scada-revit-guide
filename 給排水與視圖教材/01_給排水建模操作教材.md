## 第 1 章　建立建模基準與底圖

本章目標：讓機電模型使用可核對的樓層、網格與 CAD 參考資料。開始前應已有建築 RVT 連結與機電專案副本。

<a id="m01"></a>
### M01　複製／監視網格線

來源影片：01_複製監視網格線_字幕.mp4｜時間碼逐字稿



目的：將建築連結中的網格複製到目前專案，並建立監視關係。

1. 開啟能看見建築網格的平面視圖。
2. 執行「協同作業 → 複製／監視 → 選取連結」，再點選建築 RVT。
3. 選「複製」，需要一次選多條時啟用「多個」，配合 Ctrl 加選目標網格。
4. 先完成多重選取／複製動作，再完成並退出「複製／監視」模式。

完成檢核：目前模型中有目標網格，位置與名稱可對照來源。監視的作用是提示協調變更，不能理解成建築變更後機電網格會自動同步移動。官方功能依據見校正表 S01。

<a id="m02"></a>
### M02　複製／監視樓層

來源影片：02_複製間視樓層線_字幕.mp4｜時間碼逐字稿



1. 開啟立面或剖面，辨認目前專案的樓層與建築連結的樓層。
2. 使用「複製／監視 → 選取連結 → 複製」，選取目前缺少的樓層。
3. 檢查高程與命名後完成操作，避免把已有的樓層重複建立。

完成檢核：可逐一說出每個目標樓層的來源及高程。原片名稱中的「複製間視」校正為「複製／監視」。

<a id="m03"></a>
### M03　為樓層建立平面視圖

來源影片：03_加入平面視圖_字幕.mp4｜時間碼逐字稿



1. 在專案瀏覽器確認哪些樓層尚無需要的平面圖。
2. 使用「視圖 → 平面視圖 → 樓板平面圖」，選擇缺少的樓層，例如案例中的 B1、3F。
3. 建立後，從專案瀏覽器開啟各圖，確認關聯樓層與視圖名稱。

完成檢核：樓層基準存在，且對應平面圖可開啟。樓層與平面圖是不同物件；不能只因立面上有樓層線，就認為平面圖已經建立。

<a id="m04"></a>
### M04　連結建築 CAD 並對位

來源影片：04_連結CAD底圖_字幕.mp4｜時間碼逐字稿



1. 開啟器具放置樓層的平面圖；案例為二樓。
2. 使用「插入 → 連結 CAD」，確認單位與原 DWG 實際繪圖單位一致。案例建築底圖使用 cm。
3. 若僅作該視圖的 2D 底圖，勾選「僅目前視圖」。案例先採中心到中心放置。
4. 使用「對齊」，先選建築模型的基準網格，再選 CAD 對應網格；另一方向也要核對。
5. 檢查已知尺寸，確認沒有 10 倍或 1000 倍比例錯誤，再釘住底圖。

完成檢核：X、Y 方向及比例皆相符。底圖的暫時放置方式不能取代專案座標約定。器具所在樓層與下層吊管所在樓層應分開辨認。

## 第 2 章　放置衛工裝置並控制視圖

本章目標：器具應有正確位置、主體與接點，並能在合適視圖中被辨認。

<a id="m05"></a>
### M05　載入衛工裝置族群

來源影片：05_載入衛工裝置_字幕.mp4｜時間碼逐字稿



1. 使用「插入 → 載入族群」，找到課程的廚具及衛浴／衛工裝置 RFA。
2. 載入壁掛臉盆、馬桶、蓮蓬頭與落水頭等案例元件。
3. 選用能提供所需管接點的族群；外觀相同的建築元件未必有 MEP 接點。
4. 載入後檢查可選類型，並在測試視圖確認接點是否存在。

完成檢核：能選到所需器具，並辨認給水與排水接點。舊版族群若需升級，使用工作副本保留來源版本。

<a id="m06"></a>
### M06　依主體方式放置器具

來源影片：06_放置衛工裝置-1_字幕.mp4｜時間碼逐字稿



1. 執行「系統 → 衛工裝置」，從類型選擇器挑選器具。
2. 壁掛蓮蓬頭、壁掛臉盆依族群允許的方式放在垂直面；馬桶、落水頭依適當面放置。
3. 若族群採工作平面放置，先確認目前工作平面及方向。
4. 初放後用平面、立面與 3D 檢查方向和安裝高度。

完成檢核：器具依正確主體放置。原片示範的三種放置按鈕，是否出現取決於族群的主體設定，不能套用到所有 RFA。

<a id="m07"></a>
### M07　重新指定主體、對位與找回落水頭

來源影片：07_放置衛工裝置-2_字幕.mp4｜時間碼逐字稿



1. 壁掛元件附到錯誤牆面時，使用可用的「點選新主體」功能，重新指定正確面。
2. 以參考平面標示 CAD 上的器具中心，再用「對齊」定位模型器具。
3. 落水頭看不到時，先在 3D 確認元件存在，再取消選取物件，查看平面圖的「視圖範圍」。
4. 核對底部與視景深度是否涵蓋器具。案例向下延伸 100 mm；應依實際標高與專案單位輸入。

完成檢核：器具中心可對照 CAD，且各器具能在適當視圖辨認。看不見時先排查視圖，不直接重放同一元件。視圖範圍原理見 S04。

<a id="m08"></a>
### M08　使用天花板反射平面圖檢視吊管

來源影片：08_天花反射圖解釋_字幕.mp4｜時間碼逐字稿



1. 開啟下層的天花板反射平面圖，案例為一樓天花板管道視圖。
2. 用剖面辨認二樓器具、樓板與一樓上方吊管之間的關係。
3. 依實際位置調整切割平面、頂部與向上延伸的視景深度，確認需要的器具與管線能顯示。

完成檢核：能解釋樓板平面圖向下看、天花板反射平面圖向上看的差異。原片「1200」缺乏完整基準與欄位資訊，教材不把它設為固定值。反射平面圖的底部設定也不能照搬樓板平面圖的規則，見 S04。

<a id="m09"></a>
### M09　連結排水 CAD 底圖

來源影片：09_連結排水CAD底圖_字幕.mp4｜時間碼逐字稿



1. 在預定繪製吊管的天花板反射平面圖執行「連結 CAD」。
2. 案例排水底圖使用 mm，與 M04 建築底圖的 cm 不同；逐檔確認單位。
3. 對齊已確認的建築基準與 CAD 參考線，核對比例後釘住。

完成檢核：排水 CAD 與建築、器具位置相符，而且僅出現在預期視圖。

## 第 3 章　立管與剖面操作

本章目標：以系統類型、管類型、直徑及起迄高程共同定義管線。

<a id="m10"></a>
### M10　建立 WP 立管

來源影片：10_立管繪製_字幕.mp4｜時間碼逐字稿



1. 以 CAD 圓心或參考平面交點定位立管中心；需要時切換鎖點。
2. 執行「系統 → 管」，分別設定管類型與系統類型。案例皆命名為 WP。
3. 選案例標稱直徑 DN50，設定起點相對高程 0 mm。
4. 點定平面位置後，將另一端高程設定為 4000 mm，完成垂直管段。
5. 以剖面或 3D 確認垂直長度，必要時將詳細等級改為細緻。

完成檢核：立管定位正確、上下端高程正確。原文把管顯示粗細說成「粗糙度」；本段應理解為視圖詳細等級，管壁粗糙度另有工程用途。

<a id="m11"></a>
### M11　複製並改成 VP／SP 立管

來源影片：11_複製立管_字幕.mp4｜時間碼逐字稿



1. 選取已建立的立管，執行「複製」，需要連續複製時啟用「多個」。
2. 若目標中心不在水平或垂直方向，依需要取消複製時的方向約束。
3. 將副本放至各立管中心，再分別調整管類型、系統類型與直徑。
4. 案例 VP 為通氣管、SP 為接馬桶的污水管；縮寫以專案系統表為準。

完成檢核：複製後不會殘留錯誤系統或管徑。「2 吋約 DN50、4 吋約 DN100」是案例標稱對應，不能用英吋乘 25.4 當作管外徑。

<a id="m12"></a>
### M12　修復連結路徑

來源影片：12_管理連結_字幕.mp4｜時間碼逐字稿



1. 開啟「管理 → 管理連結」，確認連結狀態與目前路徑。
2. 選取找不到的連結，使用「重新載入自／重新載入位置（Reload From）」指定正確檔案。
3. 載入後核對模型位置、版本與顯示內容。

完成檢核：狀態恢復且位置一致。僅修復路徑，不能據此認定新版模型內容也與舊版相同。

<a id="m13"></a>
### M13　使用沿管心方向的剖面銜接立管

來源影片：13_立管連結_字幕.mp4｜時間碼逐字稿



1. 以參考平面連接兩支目標立管的中心，作為剖面方向。
2. 建立與該方向平行的剖面，收窄裁剪範圍與遠端裁剪深度。
3. 前往剖面，從目標管接點繪管或建立類似管，連至另一支立管。
4. 檢查接頭、連接狀態與標高；需要時清理妨礙選取的輔助物件。

完成檢核：剖面能看清兩支管及中間接頭。來源後半段有大量交談與辨識失真；VP 與 SP 的實際連接方式，回到設計系統及詳圖確認，不能把課堂討論當成單一通用接法。

## 第 4 章　SP、WP 支管與器具銜接

本章目標：從可辨認的接點開始配管，在平面與剖面中同時控制位置、坡度與管件。

<a id="m14"></a>
### M14　從 SP 立管開水平支管

來源影片：14_SP立管開水平管_字幕.mp4｜時間碼逐字稿



1. 將 SP 立管中心與馬桶排水接點方向用參考平面連起，再建立同方向剖面。
2. 在剖面建立案例管底 3300 mm 的參考線，清楚標示相對樓層。
3. 從立管開支管，依繪製方向設定向上或向下傾斜。案例從幹管畫向器具，使用向上傾斜。
4. 用剖面檢查實際管底，不能把管中心偏移直接填成管底高程。

完成檢核：水流方向的高程遞減，且管底達案例目標。高程控制與斜度工具見 S02、S03；本課未提供完整排水設計計算。

<a id="m15"></a>
### M15　替換順水三通並連接馬桶

來源影片：15_SP配管-1_字幕.mp4｜時間碼逐字稿



1. 選取管配件，在類型選擇器中改成課程的順水三通族群。
2. 在剖面中核對配件方向，將支管底部對到案例參考線。
3. 由馬桶排水接點繪製管段，再用「修剪／延伸至角落」或接點連接完成銜接。
4. 檢查是否真有連接、管徑是否相容及接頭是否合理。

完成檢核：馬桶排水與 SP 支管連成可追蹤的路徑。「順踢／順水梯」整理為順水三通；實際 RFA 名稱依課程資源庫。

<a id="m16"></a>
### M16　新增分支並安裝清潔口

來源影片：15_SP配管-2_字幕.mp4｜時間碼逐字稿



1. 依需要將彎頭替換為具有分支的管配件，選用適合方向的順水三通。
2. 若可選類型過多，可利用「限制至佈線偏好」縮小候選範圍。
3. 從分支接點延伸管，依案例建立 45° 轉向；確認接頭可用空間。
4. 清潔口相關零件應維持接點銜接，再依課程族群及可用的開放末端加蓋功能收尾。

完成檢核：分支方向正確，清潔口與管線有連接。課堂將零件靠近，是案例調整；模型外觀貼合不能代替產品承插或安裝尺寸。

<a id="m17"></a>
### M17　從 WP 立管開支管

來源影片：16_WP立管開水平管_字幕.mp4｜時間碼逐字稿



1. 建立與預定出管方向平行的剖面，限縮視圖範圍。
2. 由 WP 管接點建立支管，案例由幹管往器具畫，採 1% 向上傾斜。
3. 使用參考線核對管底標高，再調整斜三通與彎頭的位置。

完成檢核：管底、高低端與出管方向正確。1% 是示範值；實際坡度依設計。按方向鍵微移後仍需檢查接頭是否有效連接。

<a id="m18"></a>
### M18　延伸 WP 幹支管與微調配件

來源影片：17_WP水平管繪製_字幕.mp4｜時間碼逐字稿



1. 從既有管接點使用「繪製管」，確認繼承的大小、系統與案例斜度。
2. 依底圖建立轉彎及預留分支，再將所需位置改用斜三通。
3. 對齊時辨認管中心與管外緣，必要時用 Tab 切換參考。
4. 接頭互相侵入或提示空間不足時，退回調整接頭間距，再重新對位。

完成檢核：每個彎頭與三通均有容納空間，沒有以模型互穿掩蓋連接警告。

<a id="m19"></a>
### M19　落水頭與 P 型存水彎

來源影片：18_WP配管-1_字幕.mp4｜時間碼逐字稿



1. 在平面核對落水頭接點與支管中心是否共線。
2. 從接點銜接管段，於剖面確認垂直關係。
3. 依課程的管配件設定，選用 P 型存水彎並核對入口、出口及方向。
4. 若替換後方向錯誤，檢查族群接點與連接順序；必要時在副本中重建接頭。

完成檢核：器具至排水管的存水彎方向合理且接點連通。原片的 TR 點選順序只適用於當時使用的族群，不能保證所有配件都依相同順序翻轉。

<a id="m20"></a>
### M20　臉盆下接排水

來源影片：19_WP配管-2_字幕.mp4｜時間碼逐字稿



1. 以參考線對準臉盆排水接點與支管路徑。
2. 開啟剖面，由器具接點往幹管繪製；案例使用向下傾斜。
3. 依器具接點與案例支管規格處理管徑變化，保留適當轉接件。

4. 先重新整理原報告核對已列出的問題，再重新執行相同範圍的干涉檢查，查找可能新增的衝突。
