# SCADA 電纜架｜Revit 2025.5 繁中入門指南

新建或接手 Revit MEP／SCADA 專案後，正式繪製電纜架（Cable Tray）、電管（Conduit）與 SCADA 設備之前，該做哪些設定與檢查。後面接上 2026-10-16 的實作教材：從連結建築畫出電纜架、放梯型吊架、處理「放了看不到」、篩選上色、以及廠商提供的電纜線架標籤。

適用版本：**Autodesk Revit 2025.5 繁體中文介面**。功能名稱寫成「中文名稱（English）」，路徑例如「系統 → 電氣 → 電纜架」。

**權限前提**：公司 Windows 電腦、一般使用者權限。必要流程只用 Revit 原生功能，不需要系統管理員，也不依賴 pyRevit、Dynamo、Navisworks Manage。詳見指南「九、公司電腦權限限制」。

## 文件架構

0. 開始前先判斷：新建專案或接手專案
1. 標準起手式 Step 1～15（專案單位、連結模型、共用座標、樓層／網格、工作視圖、視圖範圍、視圖樣板、篩選與上色、電纜架類型、SCADA 參數、明細表、3D 協調視圖、品質檢查視圖、瀏覽器組織、工作共用）
2. 起手 10 步
3. 建模檢查清單
4. 電纜架繪製：從連結建築到畫出電纜架（教材第一節）
5. 梯型吊架，以及吊架間距法規（教材第二節、第五節）
6. 疑難排解：放了看不到、可見性/圖形取代被視圖樣板鎖住，以及接不起來等五種情況（教材第三節、第四節）
7. 電纜架標籤：廠商提供的機電標籤族（教材第七節）
8. AutoCAD 路由資料與 Revit 欄位對應（架構建議，不是已完成的自動同步）
9. 公司電腦權限限制

篩選與 3D 上色（教材第六節）寫在 Step 8。
