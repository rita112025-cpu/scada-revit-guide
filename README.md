# SCADA 電纜架｜Revit 2025.5 繁中入門指南

新建或接手 Revit MEP／SCADA 專案後，正式繪製電纜架（Cable Tray）、電管（Conduit）與 SCADA 設備之前，該做哪些設定與檢查。後面接上 2026-10-16 的實作教材：從連結建築畫出電纜架、放梯型吊架、處理「放了看不到」、篩選上色、以及廠商提供的電纜線架標籤。另有領域與次領域、把上色存成視圖樣板、干涉檢查與 Navisworks、匯出 NWC 並整合到對方的 NWD，以及 BIM 觀念、Revit 介面、專案樣板、機電分工、電管尺寸、給排水管路與族群出圖，以及電氣、弱電、給排水、消防、空調的實務與品管。

適用版本：**Autodesk Revit 2025.5 繁體中文介面**。功能名稱寫成「中文名稱（English）」，路徑例如「系統 → 電氣 → 電纜架」。

**權限前提**：公司 Windows 電腦、一般使用者權限。必要流程只用 Revit 原生功能，不需要系統管理員，也不依賴 pyRevit、Dynamo、Navisworks Manage。詳見指南「九、公司電腦權限限制」。

## 文件架構

側欄分成「Revit 操作」與「機電實務與品管」，避免一長串沒有分組。

0. 開始前先判斷：新建專案或接手專案
1. Revit 操作 · 觀念：BIM 觀念（含建置計畫書）、Revit 介面（含檔案、族群、參數、連結）、專案樣板、機電系統分工
2. Revit 操作 · 起手式：Step 1～15（專案單位、連結模型、共用座標、樓層／網格、工作視圖、視圖範圍、視圖樣板、篩選與上色、電纜架類型與三種外型、SCADA 參數、明細表、3D 協調視圖、品質檢查視圖、瀏覽器組織、工作共用）、起手 10 步、建模檢查清單
3. Revit 操作 · 電纜架實作：交付範圍（這次要畫哪些元件）、繪製、梯型吊架（含適用階段）、吊架間距法規、放了看不到、可見性被視圖樣板鎖住、電纜架標籤、高程換算與跨樓層路由、拉線箱／接線盒與 Tray 轉電管
4. Revit 操作 · 視圖與協調：領域與次領域、把上色設定存成視圖樣板並套用、干涉檢查與 Navisworks（NWC／NWD／NWF；Navisworks 不在必要流程）、匯出 NWC 並整合到對方的 NWD（Navisworks 實作，含專案座標統一與匯出範圍設為目前視圖；不在必要流程）、只匯出自己的系統並避免建築重複
5. Revit 操作 · 管路、族群與出圖：電管尺寸、管路設定、管段繪製技巧、族群製作、圖紙與出圖、建築建模基礎、機電建模重點（給排水、灑水、電氣迴路、風管）
6. 機電實務與品管：管材與線材、電氣與緊急供電、弱電與中央監控、給排水衛生、消防、空調、電梯、建築與機電介面整合、設計圖說審查、常見施工缺失、工地用語對照
7. 資料與限制：AutoCAD 路由欄位對應（架構建議，不是已完成的自動同步）、公司電腦權限限制
8. Revit 操作 · 教學影片：Revit 教學影片操作筆記（第 39 片專案匯出族群、第 40 片連結 CAD 給水底圖、第 44 片干涉檢查、第 45 片視圖篩選）。步驟保留時間碼；辨識不清的用語用提示框標成待核對
9. Revit 機電入門課：從建立專案到管線系統配色（單元 1–10）。含時間索引、完成檢查、綜合實作與驗收表、可展開的自我測驗、快速排查表與官方說明連結；尚未對過畫面的項目用提示框標成待確認
10. Revit 相機、彩現與穿越：從靜態構圖到動畫輸出（9-1 至 9-4-3，共 6 段）。含各段時間碼、完成檢查、練習與驗收表、可展開的自我測驗、排查表與官方說明連結

篩選與 3D 上色（教材第六節）寫在 Step 8。和舊章重複的觀念已併進 BIM、Revit 介面、管路設定、視圖樣板、3D 協調與瀏覽器組織；新章不覆蓋原有步驟。
