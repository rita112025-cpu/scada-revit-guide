# SCADA 電纜架｜Revit 2025.5 繁中入門指南

新建或接手 Revit MEP／SCADA 專案後，正式繪製電纜架（Cable Tray）、電管（Conduit）與 SCADA 設備之前，該做哪些設定與檢查。後面接上 2026-10-16 的實作教材：從連結建築畫出電纜架、放梯型吊架、處理「放了看不到」、篩選上色、以及廠商提供的電纜線架標籤。另有 BIM 觀念、Revit 介面、專案樣板、機電分工、電管尺寸、給排水管路與族群出圖，以及電氣、弱電、給排水、消防、空調的實務與品管。

適用版本：**Autodesk Revit 2025.5 繁體中文介面**。功能名稱寫成「中文名稱（English）」，路徑例如「系統 → 電氣 → 電纜架」。

**權限前提**：公司 Windows 電腦、一般使用者權限。必要流程只用 Revit 原生功能，不需要系統管理員，也不依賴 pyRevit、Dynamo、Navisworks Manage。詳見指南「九、公司電腦權限限制」。

## 文件架構

側欄分成「Revit 操作」與「機電實務與品管」，避免一長串沒有分組。

0. 開始前先判斷：新建專案或接手專案
1. Revit 操作 · 觀念：BIM 觀念（含建置計畫書）、Revit 介面（含檔案、族群、參數、連結）、專案樣板、機電系統分工
2. Revit 操作 · 起手式：Step 1～15（專案單位、連結模型、共用座標、樓層／網格、工作視圖、視圖範圍、視圖樣板、篩選與上色、電纜架類型與三種外型、SCADA 參數、明細表、3D 協調視圖、品質檢查視圖、瀏覽器組織、工作共用）、起手 10 步、建模檢查清單
3. Revit 操作 · 電纜架實作：繪製、梯型吊架、吊架間距法規、放了看不到、可見性被視圖樣板鎖住、電纜架標籤
4. Revit 操作 · 管路、族群與出圖：電管尺寸、管路設定、管段繪製技巧、族群製作、圖紙與出圖、建築建模基礎、機電建模重點（給排水、灑水、電氣迴路、風管）
5. 機電實務與品管：管材與線材、電氣與緊急供電、弱電與中央監控、給排水衛生、消防、空調、電梯、建築與機電介面整合、設計圖說審查、常見施工缺失、工地用語對照
6. 資料與限制：AutoCAD 路由欄位對應（架構建議，不是已完成的自動同步）、公司電腦權限限制

篩選與 3D 上色（教材第六節）寫在 Step 8。和舊章重複的觀念已併進 BIM、Revit 介面、管路設定；新章不覆蓋原有步驟。

## 教材主題對照

併進既有章節：

- BIM 觀念與流程 →「BIM 觀念」（LOD、常見迷思、建置計畫書）
